# 陪跑（fitloop）

一个每天陪你减脂的小工具。你随口说吃了什么、练了什么，它记下来、算额度、给建议；晚上结算，第二天接着来。

不是聊天机器人套壳——**能算的归代码，要判断的归模型**。

## 它是怎么分工的

| 层 | 谁 | 干什么 |
|---|---|---|
| 语义 | 模型 | 把你的一句话拆成记录（几件事、什么类型） |
| 口径 | 代码 | 热量区间、分档、蛋白缺口、趋势、解锁 |
| 表达 | 模型 | 把数字说成人话 |

**判档、拦截、门槛全部是代码，模型没有投票权。** 这是刻意的：模型会抖，但"你今天吃 750 卡"这个判断必须每次都一样。

## 已经能做的

- 一句话拆多件事：「早上包子豆浆，中午没吃，晚上牛肉面」→ 三条，含"没吃"这种阴性记录
- 改记录：说「那是去皮的」，它会改掉那条重算，不是再记一条
- 说错体重会拦：「今天称重15kg」→ 不收，提示是不是打错了
- 睡眠不足自动降训练：「睡了4小时」→ 今天不安排训练
- 受伤/生病直接停，转就医，不再给任何计划
- 每天一次自动压缩：明细留库里，模型只看摘要
- 自由餐按进度解锁（初期 14 天不排，上限每 3 天一次）

## 怎么跑

```bash
pip install -r requirements.txt
echo "FITLOOP_API_KEY=sk-你的key" > .env
python server.py          # 端口默认 8791，可用 FITLOOP_PORT 改
# 打开 http://127.0.0.1:8791
```

第一次打开会让你填身高体重年龄，然后给出建议目标。

## 测试

```bash
python test_core.py      # 92 条断言，不调模型
python check_ui.py       # 页面自检：语法 + 元素 + 字段对齐
python eval/run_parse.py # 19 条解析评测，会调模型
```

## 素材

- `core.py` 纯计算：分档、区间合成、睡眠、医疗停止、自由餐、趋势
- `graph_app.py` LangGraph：等待 → 解析 → 追问 → 处理
- `app.py` 模型调用与记录
- `server.py` / `static/index.html` 网页界面
